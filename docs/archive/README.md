# Archived Session Documents

Place original notes, exported plans, and previous-session development documents here.

Rules:

- Preserve original text when possible.
- Do not treat archived notes as current instructions by default.
- Register each useful archived note in [`../development_archive.md`](../development_archive.md).
- If an archived note conflicts with an active document, mark it `superseded` in the archive index instead of deleting it.
